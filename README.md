# 💎 Crystal Defenders

**Crystal Defenders** es un prototipo de acción y tower defense en tercera persona desarrollado en **Unreal Engine 5**.  
El jugador debe proteger un cristal central utilizando trampas, gestión de recursos y habilidades en tiempo real para superar **15 oleadas** de enemigos cada vez más desafiantes.

---

## 🎮 Características principales

- Sistema de vida para jugador, enemigos y cristal.  
- Combate en tiempo real con sistema de combos.  
- IA enemiga con comportamiento adaptable (jugador, trampas o cristal).  
- Sistema de oleadas progresivas.  
- Construcción de trampas (2 tipos) con uso de **maná**.  
- Sistema de **combustible** para trampas específicas.  
- Sistema de niveles y progresión del jugador.  
- Cinemática inicial y menús funcionales (principal, pausa, opciones).  

---

## 🧩 Core Loop

1. Preparar defensa y colocar trampas usando maná.  
2. Enfrentar enemigos en combate directo usando combos.  
3. Obtener XP para mejorar habilidades.  
4. Mantener trampas activas y proteger el cristal.  
5. Superar 15 oleadas para completar la partida.

---

## ⚙️ Sistemas implementados

| Sistema | Descripción breve |
|----------|------------------|
| **Vida** | Salud individual para jugador, enemigos y cristal. |
| **Oleadas** | Generación progresiva de enemigos con dificultad escalonada. |
| **Construcción** | Colocación de trampas que consumen maná y combustible. |
| **Combate** | Sistema en tiempo real con combos básicos. |
| **Progresión** | Subida de nivel mediante experiencia obtenida por enemigos derrotados. |
| **Árbol de Habilidades** | Desbloquea y mejora habilidades al subir de nivel. |
| **IA Enemiga** | Cambia dinámicamente su objetivo entre jugador, trampas o cristal. |
| **UI y Menús** | HUD, menú principal, menú de pausa y opciones de audio/controles. |
| **Cinemáticas** | Secuencia introductoria que presenta el contexto y la primera oleada. |
| **Volumen** | Se puede controlar el volumen de la música y sfx desde el menú de opciones. |
